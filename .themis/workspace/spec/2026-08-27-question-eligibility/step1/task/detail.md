### T-D1 — §2 补提问资格判据与三条反向拒绝条件

**行为目标**：在 `rules.md` §2 的判据项补提问资格一句，拒绝条件项补三条反向条件，判定者项补 Agent 自检 + R1 复核。

**做法**：

1. **判据项补**：一个问题有资格进入 `QA.md`，须是执行者**无法**从既有事实、已批准记录或先例中推出答案的；能推出的一律自己判，把判断与依据写进工件，在下一个人工闸门一并呈现。
2. **拒绝条件补三条**，逐条可判：
   - 有依据却不判——能推出答案仍作为问题提出（把判断成本转嫁给评审者）。
   - 依据没读全就提建议——提方案或推荐前未穷尽既有记录。
   - **目标层 claim 缺合法来源却不问**——只问执行细节，不问"这事该不该做"本身。
3. **第三条不可省，且须写明它与前两条方向相反**。理由必须落在文字里：执行者天然倾向把目标层当作"设计已定"而不问，**只写前两条会放大这一类**（`drift-log.md` 第 `51` 行实发）。
4. **写明裁定依据**：按可恢复性排序——多问一次不留痕迹、不可恢复；判错留在工件里，由下一个人工闸门复核依据时发现。
5. **判定者项补**：提问资格由 Agent 自检、R1 评审者复核，与该节现有形态一致。
6. **不得改动现有三条拒绝条件**（判据 005 护住）。

**对应 `specify.md` 条目**：判据 SPEC-QELIG-001、002、003。

**依赖的基础任务**：无（basic 段为空）。
