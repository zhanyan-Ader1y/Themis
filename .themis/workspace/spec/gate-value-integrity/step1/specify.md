## 本节点标出、须 R2 判定的两处

### 一、新增取值叫什么、三处改成什么

**本节点的主张**：取值名为 **`已授权代行`**，含义是"评审者授权执行者继续，但未就本节点方案内容表态"。

**理由**：它把"授权"与"表态"分开——授权确实存在（所有者说了继续），表态确实没有。**执行者自创的 `授权代行` 已在实践中被证明可读**，补进合同即可，不必另发明词。

**反面理由须记明**：`已授权代行` 与 `approved` 在字面上都像"可以往下走"，**读者可能不细看差别**。若取一个更醒目的名字（如 `未表态`），误读风险更低，但会丢掉"授权确实存在"这一半事实。

**本节点不自行认定，交 R2 裁定。**

### 二、范围收窄为三处

R1 裁定说的是"既有四处"，**本节点核实后收窄为三处**——第四处（`citation-overlap-check/step1` 的 `accepted`）已由所有者在 R1 第 2 轮追认，其取值本就合法。

**须 R2 确认该收窄成立**。若 R2 认为第四处仍须处置，本 step 应恢复为四处。
