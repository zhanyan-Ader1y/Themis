## 行为条目

### SPEC-PESC-001

**命中致坏条件的命令必须被显式拒绝**，不得返回任何值。

**验收判据**：

`go run ./cmd/themis verify internal/themis/testdata/unsafe-args.md 2>&1 | grep -c '无法可靠执行'` → `≥1`

**落地前实跑**：`0`（该 fixture 不存在，工具报读取失败）。

**依据**：`scope.md` 事实（1）——致坏条件已由 `16` 个数据点刻画；所有者裁定取 (b) 精确拒绝。

### SPEC-PESC-002

**未命中致坏条件的命令必须照常执行**，既不得误拒、也不得算错。

**验收判据**：

`go run ./cmd/themis verify internal/themis/testdata/safe-args.md 2>&1 | wc -l` → `0`

**落地前实跑**：`2`（fixture 不存在，工具输出错误行）。

**该 fixture 必须至少含 `scope.md` 表中四条已证正常的模式**（`SPEC`、`\<SPEC`、`S\|P`、`SPEC*`）**与 `SPEC\>`**——后者当前被误拒，是本条最要紧的覆盖点。

**依据**：保守规则会误拒 `27` 条本可正常执行的断言（`scope.md` 事实 2），(b) 的全部价值就在这 `27` 条。

### SPEC-PESC-003

**落在引号内的 shell 元字符不得被判为 shell 语法。**

**验收判据**：

`go test ./internal/themis/ -run TestQuotedMetacharacterNotShellSyntax -v -count=1 2>&1 | grep -c '^--- PASS'` → `≥1`

**落地前实跑**：`0`（无同名测试，`-run` 不匹配任何用例）。

**依据**：`scope.md` 事实（3）——`verify.go` 第 `144` 行以子串匹配判 `>`，不区分是否在引号内；`\<` 与 `\>` 处理不一致本身即缺陷。

### SPEC-PESC-004

**致坏条件的规则必须被测试固定，而非只存在于文档里。**

**验收判据**：

`go test ./internal/themis/ -run TestUnsafeArgRule -v -count=1 2>&1 | grep -c 'PASS: TestUnsafeArgRule/'` → `≥16`

**落地前实跑**：`0`（无同名测试）。

**本条判据的命令经 impl/detail 落地时订正，订正过程如实记明。** 初稿写作 `grep -c '^--- PASS'`，**该命令数不到子用例**——`go test -v` 把子用例输出为缩进行（四个空格加 `--- PASS: TestUnsafeArgRule/plain`），`^` 锚定只匹配顶层测试。落地后实跑得 `2`（两个顶层测试），**而 `16` 个数据点全部通过**。

**三种命令的实跑值**：`^--- PASS` → `2`；不锚定的 `--- PASS` → `18`（含父用例与另一个顶层测试）；`PASS: TestUnsafeArgRule/` → **`16`**，恰为数据点数。**取第三种。**

**订正的是计数方式，不是断言的内容**——断言仍是"`scope.md` 的 `16` 个数据点各成一个子用例且全部通过"。**不是改判据去迎合实现**：实现若少写一个数据点，订正后的命令立刻得 `15`。**第 `37` 次同型实发。**

**`≥16` 对应 `scope.md` 事实（1）表中的 `16` 个数据点**，逐点成为一个子用例。**这条是 (b) 唯一的防线**——规则若判错，静默错值照旧发生，而所有者已知情接受该风险（`QA.md` 第 2 轮）。

### SPEC-PESC-005

**表格转义的命令不得执行失败，也不得遗留挂起的子进程。**

**验收判据**：

`go run ./cmd/themis verify internal/themis/testdata/table-escape.md 2>&1 | wc -l` → `0`

`go test ./internal/themis/ -run TestTableEscape -v -count=1 2>&1 | grep -c '^--- PASS'` → `≥1`

**落地前实跑**：分别为 `2` 与 `0`。

**挂起须以 `timeout` 人工复核**：`timeout 25 go run ./cmd/themis verify internal/themis/testdata/table-escape.md; echo $?` 不得为 `124`。**该条不写成判据记法**——退出码不是 stdout，断言形态取不到它。**验证节点须单独实跑并记录。**

**依据**：`scope.md` 事实（4）——本节点复现：先报 `exit status 3840`，再挂住，`timeout 25` 触发退出码 `124`。
