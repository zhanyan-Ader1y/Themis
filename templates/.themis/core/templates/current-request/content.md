## 治理边界

- 只有用户确认且绑定 exact Source Event fragments 的 claims 才能进入本 revision。
- Agent analysis、temporary Specification、Plan、历史记录和 Summary 都不是用户语义来源。
- 每个 rendered claim 必须与 paired `record.md` 中的 claim revision、disposition 和 source fragments 一致。
- 任何变化都创建新的 immutable pair；只有完整物化、重读后才能更新 separate current pointer。
