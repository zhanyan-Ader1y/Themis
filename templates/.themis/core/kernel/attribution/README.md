# Attribution Package

## Responsibility

Attribution 是可选 post-delivery observer，用可核验证据关联完成的 outcome、changes、runs 与 supporting evidence，并区分 measurement、correlation 和 interpretation。

## Boundary

- 不进入 Global Control Rule 的核心 lifecycle。
- 不阻塞 Review、Verify、Human Acceptance、Summary、Knowledge candidate 或 lifecycle completion。
- 不修改实现、源证据、Context 或 lifecycle state。
- 不从相关性自动断言因果。
- 可复用结论只能成为独立 Knowledge candidate。

## Current status

Plan 90 才定义 metrics、privacy、retention、artifact 与 automation。当前仅保留非阻塞边界，不声明 analytics 能力可用。
