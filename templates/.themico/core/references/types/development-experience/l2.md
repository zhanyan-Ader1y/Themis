# development-experience L2

## 公共头部

与其余两种类型共享同一个 L2 公共头部（完整定义见 `.themico/core/references/common/knowledge-record.md`）：`core_conclusion`、`applicable_when`、`not_applicable_when`、`impact`、`evidence_summary`、`upgrade_when`。

## 类型化 payload（`DevelopmentExperienceL2`）

| 字段 | 说明 |
| --- | --- |
| `symptoms` | 观察到的现象/症状列表。 |
| `preconditions` | 该经验成立所需的前置条件列表。 |
| `observed_facts` | 已确认的具体事实列表。 |
| `recommended_action` | 建议采取的行动列表。 |
| `evidence_strength` | 证据强度（单一字符串，不是数组）。 |
| `risks` | 采取建议行动可能伴随的风险列表。 |
| `stop_conditions` | 应当停止采纳本经验的条件列表。 |

除 `evidence_strength` 为单一字符串外，其余字段均为字符串数组，写入前会被 CLI 排序去重；每一项都应是独立、可核对的陈述。
