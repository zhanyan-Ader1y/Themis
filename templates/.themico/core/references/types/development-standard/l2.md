# development-standard L2

## 公共头部

与其余两种类型共享同一个 L2 公共头部（完整定义见 `.themico/core/references/common/knowledge-record.md`）：`core_conclusion`、`applicable_when`、`not_applicable_when`、`impact`、`evidence_summary`、`upgrade_when`。

## 类型化 payload（`DevelopmentStandardL2`）

| 字段 | 说明 |
| --- | --- |
| `lifecycle_stages` | 本规范适用的生命周期阶段列表。 |
| `trigger` | 触发本规范生效的条件列表。 |
| `required_actions` | 触发后必须执行的动作列表。 |
| `prohibited_actions` | 触发后禁止执行的动作列表。 |
| `verification` | 验证是否遵守本规范的方法列表。 |
| `exception_policy` | 允许的例外情形及其处理方式列表。 |

以上字段均为字符串数组，写入前会被 CLI 排序去重；每一项都应是独立、可核对的陈述。
