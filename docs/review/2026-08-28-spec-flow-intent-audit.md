## 二、实践与条款的偏离：一处严重、两处轻微

### 严重：验证身份独立在 `11` 次中失效 `10` 次

**原设计 `SPEC-VERIFY-001` 的 AC1 原文**：同一执行身份既 impl 又 verify → **拒绝**。

**实测**：`11` 份 `verify/detail.md` 中，**`10` 份自承"身份独立不成立"**。唯一成立的一份是 `2026-08-19-core-removal/step1`——它以 SDD 派发的独立子代理身份运行。

**这不是记录不实**：十次都在工件里如实写明了，并标注"证据强度低于独立验证"。**但按 AC1，这十次都应被拒绝，而它们全部通过了验收。**

**成因**：soft 执行器下无派发层。**十次自承里都写了这一句**，也就是说执行者每次都知道，每次仍继续。

**这是本次审阅发现的最严重偏离**——不是条款被改写，是**条款被一致地、有记录地绕过**。

### 轻微一：`themis` CLI 的强制面远小于"凡不能信 Agent 自觉的才机器化"

**原设计地基第 2 条**：Agent 只产提案、Human 只授权、执行器只保证闸门与状态；**凡"不能信 Agent 自觉"的（gate、失效、身份、状态）才机器化**。

**实测**：`themis` CLI 目前只做两件事——重跑断言比对（`verify`）、引用重叠检出（`overlap`）。**gate、失效级联、身份、状态四项一项未机器化**，`rules.md` 中明写"本节不由机器执行"的有 `2` 节。

**这是能力未达，不是意图偏离**——`README.md` 明写当前为 soft 执行器、机器强制 `unavailable`，与设计的"默认 soft、CLI 可用时升级"一致。**但须记明：设计所列的四项机器化对象，恰恰一项都还没做。**

### 轻微二：追问从"多轮"收敛为"零到一问"，方向对但有代价

**实测各实例的问题数**：早期 `4`、`6`、`3`，晚期 `1`、`0`、`1`、`0`。

**这是 `2026-08-27-question-eligibility` 的判据在起作用**，方向与原设计 §B「多轮进行」不冲突——该节要求的是"未答不得判收敛"，不是"必须多问"。

**但本次审阅发现一处代价**：`2026-08-28-pipe-escape-handling` 零提问，而**它的核心诊断是错的**。该实例的 `QA.md` 写着"目标层无悬问"，因为目标层 claim 有来源（前一个需求的 verify 工件加当场重测的三个数）。

**来源确实合法**——错的不是提问资格判据，**是执行者把"症状真实"当成了"诊断正确"**：命令确实返回了 `0`，但把它归因到工具的 `\|` 处理，未逐层复现即写入 `Intent.md` 并取得 R1 批准。

**这暴露判据的一处盲区**：§2 的三条拒绝条件管"该不该问"，**不管"自己判的对不对"**。

## 四、结论

**结构上未偏离**：十二条锁定项全部在位，本会话新增内容均在其内展开。

**实践上有一处严重偏离**：**验证身份独立在 `11` 次中失效 `10` 次，且十次都通过了验收**。原设计对此的处置是"拒绝"，实际处置是"如实记录后继续"。

**须由所有者裁定的一项**：这十次的处置是否可接受。两条路各有代价——

- **认可现状**：承认 soft 执行器下身份独立不可得，**应修改 `SPEC-VERIFY-001` 的 AC1**，使条款与实践一致；否则条款长期处于"写着拒绝、实际全过"的状态。
- **恢复条款效力**：验证须由独立子代理承担（`2026-08-19-core-removal` 证明可行），**代价是每个 step 多一次派发**。

**执行者不自行判定**：AC1 属 `2026-08-07` 已审批文件的锁定内容，其原文写明"落地时不得再自行改写"。

## 五、本次审阅自身的局限

- **只查了控制面四份文件与 `11` 个 spec 实例**，未查 `docs/` 下其他设计文件是否与 MVP spec 一致。
- **"结构在位"不等于"语义未变"**：本文用 `grep` 证明条款字样还在，**证不出它的含义没被后续改动稀释**。逐条语义比对未做。
- **本文由执行者撰写，而偏离的主体也是执行者**——与被审对象同一身份，**证据强度低于独立审阅**。

## 六、本文自身发生的一次同型错误，如实记明

**D7 那行的证据命令初稿写作 `grep -c '实现依据须以代码为事实源'`，实跑得 `0`。**

**原因是那句话是执行者杜撰的**——`rules.md` §1 的实际措辞是拒绝条件里的"以文档而非代码为事实源"。**结论（D7 未偏离）是对的，证据命令是编的。**

由 `themis verify` 抓到并订正。**本项目第 `32` 次同型实发**，且**发生在一份专门审查"是否偏离"的文件里**——审查者本人在审查过程中偏离了"断言须由实跑得出"这一条。
