# Project

AGENTS.md takes precedence over CLAUDE.md.

This is an SDD Harness framework that enables self-accumulation of knowledge.

## Role

This is the Themis source repository. It can build a local AI coding framework for team projects that users install into
their own projects.


### Ability


#### Init

Initialize Themis in the target project.


#### Upgrade

Upgrade Themis in the target project.

## Script Documentation

Every shell script must include comments that explain its purpose, operating boundary, and the reason for non-obvious behavior. Public functions and major validation or control-flow sections must document what they do, their expected inputs or outputs where applicable, and why the behavior is necessary. Keep comments accurate when implementation changes.
