# development-standard factory

## type identity

`knowledge_type`: `development_standard`。

## 唯一 Zone

`project_knowledge`。CLI 会拒绝任何把 `development_standard` 绑定到其他 Zone 的候选或记录。

## 适用分类依据

材料主要回答"触发后必须、禁止或验证什么"——即一条对未来行为有约束力的规则：在什么条件下触发，触发后必须做什么、禁止做什么、如何验证是否遵守。

## 不适用分类依据

- 若材料只是一次设计取舍的结论和理由，属于 `design_decision`，不选本类型。
- 若材料是条件化的观察经验而非强制规则，属于 `development_experience`，不选本类型。
