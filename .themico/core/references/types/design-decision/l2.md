# design-decision L2

## 公共头部

与其余两种类型共享同一个 L2 公共头部（完整定义见 `.themico/core/references/common/knowledge-record.md`）：

- `core_conclusion`：一句话结论。
- `applicable_when`：适用条件列表。
- `not_applicable_when`：不适用条件列表。
- `impact`：影响范围列表。
- `evidence_summary`：证据摘要列表。
- `upgrade_when`：需要升级读取 L3 全文的条件列表。

## 类型化 payload（`DesignDecisionL2`）

| 字段 | 说明 |
| --- | --- |
| `affected_units` | 受本决策影响的单元列表（例如模块、组件、接口）。 |
| `constraints` | 本决策施加或依赖的约束列表。 |
| `alternatives` | 曾经比较过的备选方案列表。 |
| `consequences` | 本决策带来的后果列表（正面与负面均可）。 |
| `reevaluate_when` | 需要重新评估本决策的触发条件列表。 |

以上字段均为字符串数组，写入前会被 CLI 排序去重；填写时不需要自行排序，但每一项都应是独立、可核对的陈述，不要把多条内容合并进同一个数组元素。
